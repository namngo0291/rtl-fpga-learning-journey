# LED Blink Hardware Demo

## Board

- FPGA board: EBAZ4205
- Expansion board: HELLOFPGA EBAZ4205 expansion board
- External oscillator: 50 MHz
- Clock input: N18
- Reset button: KEY1 / T19
- LEDs: H18, K17, R18

## Expected Behavior

| Action | Expected Result |
|---|---|
| Release KEY1 | LED1, LED2, LED3 blink at different rates |
| Press KEY1 | LEDs reset to initial state |
| Release KEY1 again | LEDs start blinking again |
