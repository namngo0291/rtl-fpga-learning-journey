# RTL/FPGA Learning Journey

I am a Biomedical Electronics Engineer transitioning into RTL/FPGA design.

This repository documents my hands-on learning journey with Verilog, Vivado, digital logic design, simulation, waveform analysis, and FPGA implementation.

## Current Focus

I am currently learning how to build reusable RTL modules.  
The `03_clock_divider` project focuses on generating clock enable pulses instead of creating a new divided clock.
